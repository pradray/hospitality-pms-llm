# Hospitality PMS Assistant

Ask about Oracle OPERA Cloud APIs, configuration, or integration troubleshooting.

Answers are grounded in a corpus of OHIP API specifications, the OPERA Cloud User Guide, and Oracle Postman collections — retrieved chunks are shown as sources beneath each answer.

Examples:

- *A POS system needs to post a restaurant charge to a guest's room, but only knows the room number. What API calls are needed, in what order?*
- *Which OPERA Controls enable automatic room assignment at check-in?*
- *A partner gets 403 on postBillingCharges for a confirmed reservation. Why?*
